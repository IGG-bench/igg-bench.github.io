Abstract

GUI grounding benchmarks ask whether an agent can localize a target that is already visible in a static screenshot. Real interfaces often violate this assumption: a target may be off-screen, appear only after a state change or hover, remain occluded, or become actionable after a delay. This leaves the ability to recover target visibility unevaluated. To measure this reveal step, we introduce Interactive GUI Grounding (IGG), a benchmark in which an agent must first make the target visible through interaction and then click it. IGG contains 601 tasks across 16 controllable GUI environments and seven visibility-constraint sub-types, with a compact action space of scrolling, moving, dragging, waiting, and clicking. In our human study, participants achieve 94.6% accuracy, while GPT-5.5 reaches 79.4% and the strongest evaluated open-source VLM reaches only 31.6%. To identify the source of this gap, we conduct two controlled interventions. Telling Qwen3-VL which interaction to perform raises its accuracy only from 30.8% to 33.9%, whereas performing the interaction for the model raises it to 81.9%. The bottleneck is executing the reveal interaction, not recognizing the target once it is exposed. We further show that this capability is learnable, demonstrating that visibility recovery can be strengthened consistently across model families.

Static vs. interactive grounding

Static grounding benchmarks hand the model a screenshot in which the target is already on screen. In IGG the target starts out hidden or inactive, so the agent first has to reveal it and only then localize it. Like static grounding, IGG scores a single final click.

Benchmark

IGG has 601 tasks in 16 controllable environments modeled on familiar applications. Tasks fall into seven sub-types under three constraint types. The agent sees only screenshots, the instruction, and its own action history; the DOM and accessibility tree stay hidden. An episode succeeds on the first click that hits the target, within a budget of eight actions.

Results

Humans vs. models

Humans solve 94.6% of tasks. GPT-5.5 reaches 79.4%, and no open model solves a third. Movable occlusion and dynamic targets stay hard even for GPT-5.5.

Where does interactive grounding fail?

Telling Qwen3-VL which interaction is needed barely helps. Performing the interaction for it brings accuracy to 81.9%, above GPT-5.5 on the full task. In failed runs, the model usually never tries the action the task needs.

Learning missing interaction priors

Base models never emit DRAG, so reinforcement learning alone has nothing to reinforce. Frequency-balanced SFT first brings rare reveal actions into the policy, and online GRPO then improves them. The same recipe works across three 8B models.
